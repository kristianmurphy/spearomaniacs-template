STOREFRONT TEMPLATE - START HERE
================================

This folder is the WEBSITE. It runs at http://localhost:3000.
The separate spearomaniacs-cms-template folder is the CONTENT STUDIO. It runs at
http://localhost:3333.

IMPORTANT
---------
Create a new Sanity project for this website. Never use the Spearomaniacs production
project ID 5v60gbu6.

1. CREATE THE SANITY PROJECT
----------------------------
Go to https://www.sanity.io/manage, sign in as the new owner, create a project, and use
the production dataset. Copy the new project ID.

2. FILL IN THE WEBSITE SETTINGS
--------------------------------
If this folder came from GitHub, first run:

cp .env.example .env.local

Then open .env.local in this folder and enter at least:

NEXT_PUBLIC_SANITY_PROJECT_ID=PASTE_NEW_PROJECT_ID_HERE
NEXT_PUBLIC_SANITY_DATASET=production
NEXT_PUBLIC_SANITY_API_VERSION=2024-06-01
NEXT_PUBLIC_SITE_NAME=TYPE_THE_BRAND_NAME_HERE
NEXT_PUBLIC_SITE_URL=http://localhost:3000

Do not put spaces around the equals sign. Save the file.

The Printful, Stripe, Resend, and other blank values are optional until those services
are being set up. Never copy tokens from Spearomaniacs.

3. START THE WEBSITE
--------------------
Open Terminal in this folder and run:

npm install
npm run dev

Open http://localhost:3000.

4. SET UP THE CMS
-----------------
Open START-HERE.txt inside the spearomaniacs-cms-template folder and follow it next.

5. DEPLOY TO VERCEL
-------------------
Add every value needed from .env.local to Vercel > Project Settings > Environment
Variables. At minimum add the NEXT_PUBLIC_SANITY_* and NEXT_PUBLIC_SITE_NAME values.
Use the deployed website address for NEXT_PUBLIC_SITE_URL, then redeploy.

Never commit .env.local or send it to another person after real secret tokens are added.
